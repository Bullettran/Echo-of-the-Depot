# Графический пайплайн (EchoOfTheDepot)

## Правило лицензий
- В репо — только CC0 (Kenney, OpenGameArt с меткой CC0, itch.io с фильтром CC0).
- Список источников пакета ведём в `public/assets/SOURCES.md` (что, откуда, лицензия).
- Никаких рипнутых/proprietary ассетов, даже «на время».

## Источники прототипа
- **Kenney.nl** (всё CC0): top-down паки персонажей/техники, паки иконок предметов, тайлсеты зданий/ж/д тематики. Формат паков: PNG + XML-атлас — Phaser умеет нативно: `this.load.atlasXML('items', 'items.png', 'items.xml')`.
- **OpenGameArt / itch.io** — фильтр по CC0, для добора (персонаж с 4-направленной анимацией ходьбы у Kenney часто нет).
- Векторные паки Kenney можно даунскейлить до пиксель-размера, но пиксель-паки смотрятся цельнее.

## Хранение и нейминг
```
public/assets/
  sprites/   — персонажи, враги, предметы (kebab-case: engineer-walk.png)
  tilesets/  — тайлсеты для Tiled
  maps/      — Tiled .json карты
  fonts/     — self-host woff2 (Share Tech Mono для АРХИВА)
  audio/     — W6: jsfxr/kenney звуки
  SOURCES.md
```
- Иконка предмета = `sprites/icons/{itemId}.png` (id из items.json) — смена пака = подмена папки, код не трогаем.
- Анимации: `engineer-walk-down.png` и т.п.; frameWidth/Height указываем в preload.

## Tiled
- Тайл 32px (зафиксировать на W0 по выбранному паку; масштаб камеры zoom 2 → эффективные ~64px на экране).
- Слои карты: `ground`, `decor` (tile-слои), `collision` — тайлы с property `collides: true` (можно прямо в ground/decor), объектные слои: `spawns`, `resources`, `station`, `build-spots`.
- Экспорт `.json` рядом с тайлсетом, пути относительные.
- Сущности НЕ рисуем тайлами — только объектные слои со свойствами (type, respawn, moduleId).

## Размеры и рендер
- `pixelArt: true` + `roundPixels: true` (иначе мыло), zoom камеры — целый (1/2).
- Спрайты на сетке 32; персонаж 32×32 (хитбокс ~20×16), станция/модули — кратные тайлу.

## Свет и ночь
- W1 (дёшево): полноэкранный rect с alpha по времени суток (тёмно-синий #0a0e2a).
- W2: RenderTexture — тёмный слой, в нём вырезы `destination-out` радиальными градиентами у игрока/костров/станции. Обновлять раз в кадр только позиции вырезов.
- Сначала дёшево, шейдеры/Light2D — только если маска доказанно не тянет.

## VFX
- Подбор предмета: твин bounce+fade спрайта. Удар: `setTintFill(0xffffff)` на 50 мс. Частицы: встроенные Phaser emitters (искры, пыль шагов).
- Глитчи АРХИВА и терминал — CSS (см. скил web-dom-ui), не canvas.
- Анимации ходьбы нет на прототипе: статичный спрайт + лёгкий bob-твин + пыль у ног. Живее, чем кажется.

## Своя графика (позже, опционально)
- Aseprite (~$20, стандарт) или бесплатные Piskel/LibreSprite.
- Палитра 16–32 цвета, сетка 32px, исходники `.ase` — в `assets-src/` (не в public).

## Звук (W6)
- jsfxr (jsfxr.app) — генерация 8-bit SFX в wav: выстрел/удар/пикап за минуты.
- Kenney audio паки — эмбиент/циклы.
- Порог: не начинать звук до играбельного W2-среза.

## Что ставит пользователь (руками, один раз)
1. Tiled — https://www.mapeditor.org (бесплатно).
2. Скачать 1–2 Kenney-пака (zip) → распаковать в public/assets/.
3. Опционально: Aseprite/Piskel — только если рисуем своё.
Больше ничего: атласы Kenney уже в формате Phaser, паковать нечем и не нужно до ~50 уникальных спрайтов.

# DOM UI поверх canvas (EchoOfTheDepot)

## Железные правила
1. **UI получает данные только через EventBus** (подписка). Опрос мира из UI (rAF-циклы с чтением GameState) запрещён — перенос правила Event Dispatchers из UE.
2. **UI-код не импортирует Phaser** и не трогает canvas. Мир не читает DOM.
3. Мост — `src/bridge/world-to-dom.ts`: единственное место, знающее обе стороны.
4. Команды игрока из UI (крафт, экипировка) — события `ui:*` обратно в шину, мир валидирует.

## Слои (z-index)
```
z1 hud        — полоски статов, часы, промпт «E — Починить»
z2 archiv     — нижняя лента-терминал
z3 panels     — инвентарь (Tab), крафт; открытие = pause мира
z4 toasts     — короткие «+2 Металлолом»
z5 pause/menu
```
- Контейнер UI: `position: absolute; inset: 0; pointer-events: none;` — события мыши включать точечно (`pointer-events: auto`) только на интерактивных панелях, чтобы клики проходили в canvas.

## Типизированный EventBus
```ts
interface EventMap {
  'stats:changed': { stat: E_StatType; value: number };
  'archiv:say': { lineId: string; text: string; glitch: boolean };
  'ui:craft:requested': { recipeId: string };
}
```
- Каждый UI-модуль: класс с `mount()`/`destroy()`, подписки снимает в `destroy()` — иначе дубль рендера после переоткрытия.

## Терминал АРХИВА (визитная карточка)
- Очередь реплик: новая строка НЕ прерывает текущую — очередь с таймстампами.
- Эффект печатной машинки: посимвольный reveal через rAF (~30 мс/символ).
- Плейсхолдеры `{copper}` интерполируются данными игры ДО эмитта в UI.
- Глитч: CSS — `clip-path` дёргается keyframes + `text-shadow` сдвиги; частота глитча приходит из мира (`glitch: boolean`/уровень).
- Шрифт Share Tech Mono (self-host woff2); дождаться `document.fonts.ready` до первого показа.
- `prefers-reduced-motion` — отключить глитч/печать, показывать сразу.

## Инвентарь
- CSS Grid слотов; перетаскивание — pointer events (не HTML5 drag-n-drop — он ломает тач и стили).
- Стак: бейдж-счётчик; tooltip по hover/focus (и клавиатурой).
- Панель открывается → эмит `ui:pause` (мир ставит паузу) → закрылась → `ui:resume`.

## Тосты
- Стек снизу-справа, максимум 4, авто-скрытие 2.5 с, CSS-анимация появления. Один тип сообщения = один тост-фабрикой метод.

## Гигиена перфа
- DOM меняем только по событиям, не в цикле. Полоски статов — обновление width по `stats:changed` (это норм: событие, не опрос).
- Без layout thrash: не читать `offsetWidth` в цикле записи стилей.
- CSS: токены в `:root` (--bg, --terminal-green, --accent-amber); тёмная тема — базовая, другой не планируется.

# AGENTS.md — «Поезд "Последний Редут"»

Правила проекта. Прочитать перед началом любой работы.

## Проект

- Игра: «Поезд "Последний Редут"» — изометрический survival со строительством базы-поезда.
- Визуал: изометрия в духе Diablo 3, индустриальный постапокалипсис (ржавчина, туман, тёплый свет в поезде / холодный снаружи).
- Движок: **Godot 4.x**, язык — **GDScript**.
- Лор и канон: `history.md` в корне проекта. Единственный источник правды по миру.

## Главные правила

1. **ВЕСЬ код комментируется.** Комментарии на русском языке:
   - каждый скрипт начинается с заголовочного комментария (назначение скрипта);
   - каждая функция — с краткого описания (что делает, аргументы, возврат если неочевидно);
   - неочевидная логика поясняется построчно.
2. Работа поэтапная: сначала обсуждение и декомпозиция с пользователем, потом код. Не опережать пользователя и не писать код без запроса.
3. Не начинать новые большие системы без согласования.
4. Лор не выдумывать. Если факта нет в `history.md` — помечать как предположение и предлагать пользователю решение. Пункты со статусом «TBD» не канонизировать самовольно.
5. Ничего не коммитить/не пушить без явной просьбы пользователя.

## Соглашения по коду (GDScript, Godot 4.x)

- Типизация везде, где возможно: `var speed: float = 100.0`, `func take_damage(value: int) -> void`.
- Именование:
  - файлы и функции — `snake_case`;
  - сцены и узлы (Node) — `PascalCase`;
  - константы — `SCREAMING_SNAKE_CASE`.
- Сигналы: объявлять через `signal`, имена в прошедшем времени (`damage_taken`, `item_collected`).
- Один скрипт — одна ответственность. Godot-идиоматика: композиция сцен, сигналы вместо жёстких ссылок.
- Экспортируемые параметры (`@export`) — для всего, что тюнится дизайнеру из редактора.
- Изометрия: для правильного перекрытия объектов — Y-sort; движение персонажа — в мировых координатах, без «ступенек» по тайлам.

## Структура каталогов (создавать по мере необходимости, не заранее)

```
scenes/      — сцены (.tscn)
scripts/     — скрипты (.gd)
assets/
  sprites/   — спрайты и спрайт-листы
  audio/     — звуки и музыка
data/        — конфиги (предметы, вагоны, рецепты) в JSON или .tres
docs/        — документация и дизайн-решения
```

## Скиллы проекта

- `game-lore` — использовать для всего, что касается сюжета, квестов, реплик АРХИВА, имён и фракций.

- `animated-sprites` — использовать при создании/подключении анимированных спрайтов.
